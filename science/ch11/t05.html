Resistors in series and in parallel

About 55 minutes · 4 things to learn
By the end you can…
  • Describe Activities 11.4–11.5 (CBSE Practical 5) and use the series rules — same current, V = V1 + V2 + V3, Rs = R1 + R2 + R3.
  • Describe Activity 11.6 (CBSE Practical 5) and use the parallel rules — same p.d., I = I1 + I2 + I3, 1/Rp = 1/R1 + 1/R2 + 1/R3.
  • Solve mixed series–parallel networks and design combinations of given resistors.
  • Give the disadvantages of a series arrangement and the advantages of a parallel arrangement for appliances.

A string of festival lights goes completely dark when one tiny bulb fails, and the electrician has to test every bulb to find it. Yet at home, when one bulb fuses, the fan and the television keep working. The difference is not in the bulbs — it is in how they are joined.

Quick reminder (fractions)

To add 14+16\dfrac{1}{4} + \dfrac{1}{6}41​+61​, use the LCM 12: 312+212=512\dfrac{3}{12} + \dfrac{2}{12} = \dfrac{5}{12}123​+122​=125​. The reciprocal of 512\dfrac{5}{12}125​ is 125\dfrac{12}{5}512​ — you get it by turning the fraction upside down.

There are two ways of joining resistors:

  • in series — end to end, one after another, so there is only one path for the current (Fig 11.6);
  • in parallel — side by side between the same two points X and Y, so the current divides among several paths (Fig 11.7).

The single resistor that could replace a combination — giving the same current for the same p.d. — is called its equivalent resistance.

  1. Mixed networks — the network routine

  1. Draw the circuit and label every resistor.
  2. Reduce the innermost group first: a parallel group → one equivalent resistor; a series chain → one resistor. Redraw after each step.
  3. Total current from Ohm's law: I=VRtotalI = \dfrac{V}{R_{\text{total}}}I=Rtotal​V​.
  4. Go back out: the same current flows through resistors in series; the same p.d. is across resistors in parallel.
  5. Check: branch currents add up to the current that entered; p.d.s round the loop add up to the battery's p.d.

  1. Why appliances at home are joined in parallel

  • Series is impractical for appliances: a series circuit has the same current in every part, but a bulb and a heater need currents of very different sizes to work properly.
  • In series, if one component stops working, the loop is broken and every other component stops too — like festival lights, where each bulb has to be tested to find the dead one.
  • A parallel circuit divides the current among the appliances, gives each one the full supply p.d., and lets each draw the current it needs. The total resistance is decreased as 1Rp=1R1+1R2+…\dfrac{1}{R_p} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \dotsRp​1​=R1​1​+R2​1​+… says. One appliance can be switched off, or can fail, while the others go on working.

(How the wiring of a house is actually laid out — and the fuse that protects it — is studied in Chapter 12, Magnetic Effects of Electric Current.)

Common mistakes!

  • "In parallel, the current is the same in every resistor."

    In parallel the p.d. is the same; the current divides (more through the smaller resistor).

    Series → same current; parallel → same p.d.

  • "In series, each resistor gets the full battery p.d."

    The p.d.s in series add up to the battery's p.d.

    V=V1+V2+…V = V_1 + V_2 + \dotsV=V1​+V2​+…

  • Giving 1Rp\dfrac{1}{R_p}Rp​1​ as the answer.

    1Rp\dfrac{1}{R_p}Rp​1​ is the reciprocal of what you want.

    Flip at the end: Rp=1(1R1+1R2)R_p = \dfrac{1}{\left(\dfrac{1}{R_1} + \dfrac{1}{R_2}\right)}Rp​=(R1​1​+R2​1​)1​.

  • "Parallel resistance is more than the largest."

    Each new path makes it easier for current to flow.

    RpR_pRp​ is less than the smallest; check every answer against this.

  • Using "product over sum" for three resistors.

    It is true only for two.

    For three, add the three reciprocals.

  • In a mixed network, putting the full supply p.d. across a parallel group.

    Part of the p.d. is across the series resistor.

    Find the total current first, then Vp=I×RpV_p = I \times R_pVp​=I×Rp​.

Key points

  • Series: one path; same current; V=V1+V2+V3V = V_1 + V_2 + V_3V=V1​+V2​+V3​; Rs=R1+R2+R3R_s = R_1 + R_2 + R_3Rs​=R1​+R2​+R3​ (larger than any one).
  • Parallel: several paths; same p.d.; I=I1+I2+I3I = I_1 + I_2 + I_3I=I1​+I2​+I3​; 1Rp=1R1+1R2+1R3\dfrac{1}{R_p} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \dfrac{1}{R_3}Rp​1​=R1​1​+R2​1​+R3​1​ (smaller than the smallest). For two only: Rp=R1R2R1+R2R_p = \dfrac{R_1R_2}{R_1 + R_2}Rp​=R1​+R2​R1​R2​​.
  • Mixed networks: reduce step by step → total current → go back out → check that currents and p.d.s add up.
  • Appliances are joined in parallel: each gets the full p.d., draws its own current and works independently; in series, one failure stops everything and all must share one current.
