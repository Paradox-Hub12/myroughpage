Linear equations in two variables — ax+by+c=0ax + by + c = 0ax+by+c=0 with a and b not both zero. The graph is a straight line; every point on it is a solution. y=ky = ky=k is horizontal (a=0a = 0a=0); x=kx = kx=k is vertical (b=0b = 0b=0).

A pair and its solution — two such equations; a solution satisfies both, so it is a point on both lines.

Three cases — intersecting lines: exactly one solution (consistent). Parallel lines: no solution (inconsistent). Coincident lines: infinitely many solutions (dependent, so consistent). Two different straight lines meet at most once, so a pair never has exactly two solutions.

Graphical method — three points per line, the same axes and scale, read the point of intersection, check it in both equations. Triangle with the x-axis: vertices = meeting point + the two x-intercepts; area =12×= \dfrac{1}{2} \times=21​× base ×\times× (y-coordinate of the meeting point (its distance from the axis — drop any minus sign)). With the y-axis, use the y-intercepts and the x-coordinate.

Ratio test (both equations in the same form; row 1 needs a2,b2≠0a_2, b_2 \neq 0a2​,b2​=0; rows 2–3 need a2,b2,c2≠0a_2, b_2, c_2 \neq 0a2​,b2​,c2​=0) — a1a2≠b1b2\dfrac{a_1}{a_2} \neq \dfrac{b_1}{b_2}a2​a1​​=b2​b1​​: one solution. a1a2=b1b2≠c1c2\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} \neq \dfrac{c_1}{c_2}a2​a1​​=b2​b1​​=c2​c1​​: none. All three equal: infinitely many. A 0 coefficient? Multiple test: find m with a2=ma1a_2 = m a_1a2​=ma1​, b2=mb1b_2 = m b_1b2​=mb1​; none → intersecting; c2=mc1c_2 = m c_1c2​=mc1​ too → coincident; otherwise parallel.

Finding k — unique → "k≠…k \neq \ldotsk=…" (check values that make a coefficient 0); no solution → solve a1a2=b1b2\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2}a2​a1​​=b2​b1​​, then test the constants for each candidate; infinitely many → k must satisfy both equalities, or "no value".

Substitution — make one variable the subject → substitute into the other equation (in brackets) → solve → back-substitute → check in both.

Elimination — line up → match one coefficient (multiply every term) → opposite signs add, same signs subtract → solve → back-substitute into an original equation → check in both.

Variables vanish — a false statement (0=70 = 70=7) → no solution; a true statement (0=00 = 00=0) → infinitely many. Never "x=0x = 0x=0".

Word problems — Let (with meaning and units) → two equations → solve → answer in words + story check. Digits: 10x+y10x + y10x+y, reversed 10y+x10y + x10y+x. Ages: "n years ago" changes both ages.

Not in this year's syllabus: the cross-multiplication method and equations reducible to a pair of linear equations (both removed from the rationalised textbook).
