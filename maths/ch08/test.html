Question 1 · MCQ

In △PQR, ∠R=90°\angle R = 90°∠R=90°, PR = 63 cm, QR = 16 cm and PQ = 65 cm. The value of sin⁡Q\sin QsinQ is:

Correct: (b)

From Q, the opposite side is PR = 63 and the hypotenuse is PQ = 65, so sin⁡Q=6365\sin Q = \dfrac{63}{65}sinQ=6563​. (a) is cos⁡Q\cos QcosQ (opposite and adjacent swapped); (c) is tan⁡Q\tan QtanQ; (d) is cot⁡Q\cot QcotQ.

Question 2 · MCQ

The value of sin⁡260°+cos⁡230°−tan⁡245°\sin^2 60° + \cos^2 30° - \tan^2 45°sin260°+cos230°−tan245° is:

Correct: (a)

34+34−1=12\dfrac{3}{4} + \dfrac{3}{4} - 1 = \dfrac{1}{2}43​+43​−1=21​. (b) uses cos⁡30°=12\cos 30° = \dfrac{1}{2}cos30°=21​ (the 30°/60° swap): 34+14−1=0\dfrac{3}{4} + \dfrac{1}{4} - 1 = 043​+41​−1=0; (c) forgets tan⁡245°\tan^2 45°tan245°; (d) uses sin⁡60°=cos⁡30°=12\sin 60° = \cos 30° = \dfrac{1}{2}sin60°=cos30°=21​: 14+14−1\dfrac{1}{4} + \dfrac{1}{4} - 141​+41​−1.

Question 3 · MCQ

If 2sin⁡2θ=32\sin 2\theta = \sqrt{3}2sin2θ=3​ and 2θ2\theta2θ is acute, then θ\thetaθ is:

Correct: (a)

sin⁡2θ=32\sin 2\theta = \dfrac{\sqrt{3}}{2}sin2θ=23​​, so 2θ=60°2\theta = 60°2θ=60° and θ=30°\theta = 30°θ=30°. (b) stops at 2θ2\theta2θ; (c) uses 2θ=30°2\theta = 30°2θ=30° (the value of cos⁡30°\cos 30°cos30°, not sin⁡30°\sin 30°sin30°); (d) multiplies by 2 instead of dividing (2θ=60°⇒θ=120°2\theta = 60° \Rightarrow \theta = 120°2θ=60°⇒θ=120°).

Question 4 · MCQ

(1−sin⁡2A)(1+tan⁡2A)(1 - \sin^2 A)(1 + \tan^2 A)(1−sin2A)(1+tan2A) is equal to:

Correct: (a)

cos⁡2A×sec⁡2A=1\cos^2 A \times \sec^2 A = 1cos2A×sec2A=1. (b) replaces 1−sin⁡2A1 - \sin^2 A1−sin2A by cos⁡2A\cos^2 Acos2A and then forgets the second bracket; (c) treats 1−sin⁡2A1 - \sin^2 A1−sin2A as 1; (d) uses 1−sin⁡2A=sin⁡2A1 - \sin^2 A = \sin^2 A1−sin2A=sin2A (rearranged form mixed up): sin⁡2Asec⁡2A=tan⁡2A\sin^2 A\sec^2 A = \tan^2 Asin2Asec2A=tan2A.
