Toolkit: patterns, substitution and solving

About 30 minutes · 3 things to learn
By the end you can…
  • Continue a number pattern and describe its rule.
  • Substitute into a formula with negatives and fractions.
  • Solve linear and simple quadratic equations for a whole-number unknown.
Why this lesson exists

This chapter uses three skills from Classes 6–9 again and again: spotting the rule in a list of numbers, putting numbers (often negative or fractions) into a formula, and solving an equation to find how many terms there are. When an answer in this chapter goes wrong, the slip is usually in one of these — a minus sign lost while substituting, or a negative answer kept for "the number of terms". If you already have these skills, prove it below and go straight to Topic 2.

Work through this toolkit — it takes about 30 minutes. Then try the questions again.

A staircase is built from wooden blocks: 3 blocks in the first step, 5 in the second, 7 in the third. How many blocks are in the 30th step? You could keep adding 2 until you reach step 30 — or you could notice the rule and jump straight there. This whole chapter is about such jumps. To make them, you need to read a pattern, substitute into a formula, and solve for the unknown position n.

  1. Reading a pattern

A list (or sequence) of numbers is written in order: first number, second number, third number, and so on. To find its rule, compare neighbours:

  • Subtract each number from the next one. If the answer is the same every time, the rule is "add that number". The answer may be negative: for 20,17,14,…20, 17, 14, \ldots20,17,14,… each difference is −3-3−3, so the rule is "add −3-3−3" (that is, subtract 3).
  • If the differences change, try dividing each number by the one before it ("multiply by 2 each time"), or compare with the squares 1,4,9,16,…1, 4, 9, 16, \ldots1,4,9,16,….

Always check every pair of neighbours you are given, not just the first pair.

  1. Substituting safely

A formula such as a+(n−1)da + (n - 1)da+(n−1)d is a recipe. To use it:

  1. Write the formula first.
  2. Replace each letter by its value inside brackets, especially negatives and fractions: (−4)(-4)(−4), (−14)\left(-\dfrac{1}{4}\right)(−41​).
  3. Work out the brackets first, then multiply, then add.

Remember: a letter written next to a bracket means multiply, so (n−1)d(n - 1)d(n−1)d means (n−1)×d(n - 1) \times d(n−1)×d. And 2a2a2a means 2×a2 \times a2×a, not a2a^2a2.

  1. Solving for a position n

In this chapter n is usually a position in a list (the 12th term) or a number of terms. So the answer must be a positive whole number.

  • Linear equations: undo one operation at a time, doing the same to both sides.
  • Quadratic equations: bring everything to one side, factorise (as in Chapter 4, Quadratic Equations), and find both roots. Then check each root: keep it only if it is a positive whole number (and makes sense in the question). A negative root, or a root such as 72\dfrac{7}{2}27​, cannot be a number of terms.

Worked example 1

Three pattern rules

Question. Describe the rule of each list and write its next two numbers: (a) 13,9,5,1,…13, 9, 5, 1, \ldots13,9,5,1,… (b) 2,6,18,54,…2, 6, 18, 54, \ldots2,6,18,54,… (c) 0,3,8,15,…0, 3, 8, 15, \ldots0,3,8,15,…

Given: three lists. Asked: each rule and the next two numbers.

Concept used: compare neighbours — first by subtracting, then by dividing, then with the squares. Why it applies: the rule of a list is found from how each number is made from the one before it.

  1. 1

    (a)

    Differences: 9−13=−49 - 13 = -49−13=−4, 5−9=−45 - 9 = -45−9=−4, 1−5=−41 - 5 = -41−5=−4. All equal.

  2. 2

    Rule: start at 13 and add −4-4−4 each time. Next: 1+(−4)=−31 + (-4) = -31+(−4)=−3 and −3+(−4)=−7-3 + (-4) = -7−3+(−4)=−7.

  3. 3

    (b)

    Differences: 444, 121212, 363636 — not equal, so it is not "add the same number".

  4. 4

    Divide: 6÷2=36 \div 2 = 36÷2=3, 18÷6=318 \div 6 = 318÷6=3, 54÷18=354 \div 18 = 354÷18=3. Rule: multiply by 3. Next: 54×3=16254 \times 3 = 16254×3=162 and 162×3=486162 \times 3 = 486162×3=486.

  5. 5

    (c)

    Differences: 333, 555, 777 — not equal; quotients do not exist (3÷03 \div 03÷0), so compare with the squares 1,4,9,161, 4, 9, 161,4,9,16.

  6. 6

    Each number is one less than a square: 1−1=01 - 1 = 01−1=0, 4−1=34 - 1 = 34−1=3, 9−1=89 - 1 = 89−1=8, 16−1=1516 - 1 = 1516−1=15. Rule: the nth number is n2−1n^2 - 1n2−1. Next: 52−1=245^2 - 1 = 2452−1=24 and 62−1=356^2 - 1 = 3562−1=35.

  7. Check: (a) −7−(−3)=−4-7 - (-3) = -4−7−(−3)=−4 ✔ (b) 486÷162=3486 \div 162 = 3486÷162=3 ✔ (c) the differences continue 999, 111111: 15+9=2415 + 9 = 2415+9=24 ✔, 24+11=3524 + 11 = 3524+11=35 ✔.

  8. Answer (a) add −4-4−4: −3-3−3, −7-7−7 (b) multiply by 3: 162162162, 486486486 (c) n2−1n^2 - 1n2−1: 242424, 353535

    Common trap: In (a), writing the difference as +4+4+4 by subtracting the other way round (13−913 - 913−9). Always subtract earlier from later: next number minus this number.

Worked example 3

Solving for n

Question. n is a positive whole number. Solve: (a) −2+(n−1)×6=64-2 + (n - 1) \times 6 = 64−2+(n−1)×6=64 (b) n2(n+7)=30\dfrac{n}{2}(n + 7) = 302n​(n+7)=30.

Given: two equations in n. Asked: n.

Concept used: undo one operation at a time; for a quadratic, factorise and test both roots. Why it applies: n is a position or a count, so only a positive whole number is allowed.

  1. 1

    (a)

    Add 2 to both sides.

    (n−1)×6=66(n - 1) \times 6 = 66(n−1)×6=66Swipe to see the whole equation →
  2. 2

    Divide both sides by 6.

    n−1=11n - 1 = 11n−1=11Swipe to see the whole equation →
  3. 3

    Add 1 to both sides.

    n=12n = 12n=12Swipe to see the whole equation →
  4. 4

    (b)

    Multiply both sides by 2.

    n(n+7)=60n(n + 7) = 60n(n+7)=60Swipe to see the whole equation →
  5. 5

    Expand the bracket.

    n2+7n=60n^2 + 7n = 60n2+7n=60Swipe to see the whole equation →
  6. 6

    Subtract 60 from both sides.

    n2+7n−60=0n^2 + 7n - 60 = 0n2+7n−60=0Swipe to see the whole equation →
  7. 7

    Factorise: two numbers with product −60-60−60 and sum 7 are 12 and −5-5−5.

    (n+12)(n−5)=0(n + 12)(n - 5) = 0(n+12)(n−5)=0Swipe to see the whole equation →
  8. 8

    So n=−12n = -12n=−12 or n=5n = 5n=5.

    Test the roots: −12-12−12 is negative, so it cannot be a position or a count — reject it. 555 is a positive whole number — keep it.

  10. Check: (a) −2+11×6=−2+66=64-2 + 11 \times 6 = -2 + 66 = 64−2+11×6=−2+66=64 ✔ (b) 52(5+7)=52×12=30\dfrac{5}{2}(5 + 7) = \dfrac{5}{2} \times 12 = 3025​(5+7)=25​×12=30 ✔.

Common mistakes!

  • Subtracting the wrong way: difference of 13,913, 913,9 written as 444

    The rule takes you from a number to the next one.

    Next minus this: 9−13=−49 - 13 = -49−13=−4.

  • Checking only the first pair of neighbours

    A list can start like a pattern and then break it.

    Check every pair you are given.

  • 6+9−1×(−5)6 + 9 - 1 \times (-5)6+9−1×(−5) instead of 6+(9−1)(−5)6 + (9 - 1)(-5)6+(9−1)(−5)

    Without brackets the order of operations changes the answer.

    Keep (n−1)(n - 1)(n−1) in brackets and work it out first.

  • Reading 2a2a2a as a2a^2a2

    2a2a2a means 2×a2 \times a2×a.

    With a=−3a = -3a=−3: 2a=−62a = -62a=−6, while a2=9a^2 = 9a2=9.

  • Keeping a negative or fractional n

    n is a position or a count.

    Test each root; reject it with a reason.

Key points

  • To find a rule, compare neighbours: subtract (next minus this), then try dividing or squares.
  • Substitute every value in brackets; brackets first, then multiply, then add.
  • (n−1)d(n - 1)d(n−1)d means (n−1)×d(n - 1) \times d(n−1)×d; 2a2a2a means 2×a2 \times a2×a.
  • n counts terms, so it must be a positive whole number: test every root of a quadratic and reject the others with a reason.
