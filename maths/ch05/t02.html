Topic 2 of 5

What is an AP?

About 45 minutes · 3 things to learn
By the end you can…
  • Explain why arithmetic progressions are useful, and define an AP, its first term a and common difference d.
  • Decide whether a list is an AP (including fractions, surds and algebraic terms), and write the first few terms from a and d.
  • Use the condition for three consecutive terms, 2b = a + c, to find an unknown.

An auto-rickshaw charges ₹ 30 for the first kilometre and ₹ 12 for every kilometre after that. The fares after 1, 2, 3, 4 km are ₹ 30, ₹ 42, ₹ 54, ₹ 66. Meera drops ₹ 20 into a jar on the first day, ₹ 25 on the second, ₹ 30 on the third. A staircase of blocks has 3, 5, 7, 9 blocks in its steps. Three different stories — and one shared rule: add the same number every time.

Why this pattern matters

When a list grows (or shrinks) by the same amount at every step, you do not need to write it all out. In the next two topics you will find any term — the fare for 25 km, the 100th step — and the total of many terms, each in one line. Fixed yearly increments in a salary, equal increases in savings, rows of seats that grow by the same number, and simple interest year by year all follow this rule.

The definition

An arithmetic progression (AP) is a list of numbers in which every term after the first is obtained by adding the same fixed number to the term just before it.

  • Each number in the list is a term. We write the terms as a1,a2,a3,…a_1, a_2, a_3, \ldotsa1​,a2​,a3​,… ("a one, a two, …"), and the first term a1a_1a1​ is usually called a.
  • The fixed number is the common difference, d. It can be positive (the list grows), negative (the list shrinks) or zero (every term is the same).
  • So d=a2−a1=a3−a2=…d = a_2 - a_1 = a_3 - a_2 = \ldotsd=a2​−a1​=a3​−a2​=… — in general, d=ak+1−akd = a_{k+1} - a_kd=ak+1​−ak​: a term minus the term just before it.

Starting from a and adding d again and again gives the general form of an AP:

a,a+d,a+2d,a+3d,…a, \quad a + d, \quad a + 2d, \quad a + 3d, \quad \ldotsa,a+d,a+2d,a+3d,…Swipe to see the whole equation →

A list that stops (it has a last term, often called l) is a finite AP; a list that goes on for ever (written with "…" at the end) is an infinite AP.

Is a list an AP? A routine

  1. Find every difference "next term minus this term" for the terms you are given.
  2. If all the differences are equal, the list is an AP, and d is that value. If even one difference is different, it is not an AP.
  3. Fractions: use a common denominator. Surds: simplify first (20=25\sqrt{20} = 2\sqrt{5}20​=25​). Algebraic terms: simplify each difference; it must be the same expression every time.

A constant list such as 4,4,4,…4, 4, 4, \ldots4,4,4,… is an AP, with d=0d = 0d=0.

Writing an AP from a and d

Start with a and keep adding d: with a=10a = 10a=10 and d=−3d = -3d=−3 the AP is 10,7,4,1,…10, 7, 4, 1, \ldots10,7,4,1,… You need both a and d — knowing only one of them does not fix the list.

Three consecutive terms

If a, b, c are three consecutive terms of an AP (in this order), the two differences are equal:

b−a=c−b⇒2b=a+cb - a = c - b \qquad\Rightarrow\qquad 2b = a + cb−a=c−b⇒2b=a+cSwipe to see the whole equation →

The reverse is also true: if 2b=a+c2b = a + c2b=a+c, then a, b, c (in this order) are in AP. The middle term b is the arithmetic mean of a and c, b=a+c2b = \dfrac{a + c}{2}b=2a+c​. This gives one equation, so it can find one unknown.

Worked example 1

Integers, fractions and a constant list

Question. Which of these lists are APs? For each AP, write d and the next two terms. (a) 17,11,5,−1,…17, 11, 5, -1, \ldots17,11,5,−1,… (b) 14,23,1312,32,…\dfrac{1}{4}, \dfrac{2}{3}, \dfrac{13}{12}, \dfrac{3}{2}, \ldots41​,32​,1213​,23​,… (c) −7,−7,−7,−7,…-7, -7, -7, -7, \ldots−7,−7,−7,−7,… (d) 4,7,10,14,…4, 7, 10, 14, \ldots4,7,10,14,…

Given: four lists. Asked: AP or not; d and the next two terms if it is.

Concept used: the "is it an AP?" routine — every difference must be the same. Why it applies: an AP is defined by a constant difference.

    (a)

    Differences: 11−17=−611 - 17 = -611−17=−6, 5−11=−65 - 11 = -65−11=−6, −1−5=−6-1 - 5 = -6−1−5=−6. All equal, so it is an AP with d=−6d = -6d=−6.

    Next two terms: −1+(−6)=−7-1 + (-6) = -7−1+(−6)=−7 and −7+(−6)=−13-7 + (-6) = -13−7+(−6)=−13.

  3. 3

    (b)

    Common denominator 12: the list is 312,812,1312,1812\dfrac{3}{12}, \dfrac{8}{12}, \dfrac{13}{12}, \dfrac{18}{12}123​,128​,1213​,1218​.

  4. 4

    Differences: 512\dfrac{5}{12}125​, 512\dfrac{5}{12}125​, 512\dfrac{5}{12}125​. An AP with d=512d = \dfrac{5}{12}d=125​.

  5. 5

    Next two terms: 1812+512=2312\dfrac{18}{12} + \dfrac{5}{12} = \dfrac{23}{12}1218​+125​=1223​ and 2312+512=2812=73\dfrac{23}{12} + \dfrac{5}{12} = \dfrac{28}{12} = \dfrac{7}{3}1223​+125​=1228​=37​.

  6. 6

    (c)

    Differences: 0,0,00, 0, 00,0,0. An AP with d=0d = 0d=0; the next two terms are −7-7−7 and −7-7−7.

Worked example 2

Surds and algebraic terms

Question. Show that each list is an AP, and write d and the next two terms. (a) 5,20,45,80,…\sqrt{5}, \sqrt{20}, \sqrt{45}, \sqrt{80}, \ldots5​,20​,45​,80​,… (b) 1+3, 3, 5−3, 7−23,…1 + \sqrt{3}, \ 3, \ 5 - \sqrt{3}, \ 7 - 2\sqrt{3}, \ldots1+3​, 3, 5−3​, 7−23​,… (c) p−2q, p+q, p+4q, p+7q,…p - 2q, \ p + q, \ p + 4q, \ p + 7q, \ldotsp−2q, p+q, p+4q, p+7q,…

Worked example 3

Writing the first four terms

Question. Write the first four terms of the AP when: (a) a=−6a = -6a=−6, d=2.5d = 2.5d=2.5 (b) a=23a = \dfrac{2}{3}a=32​, d=−16d = -\dfrac{1}{6}d=−61​ (c) the first term is 9 and the second term is 4.

Given: a and d (or two terms). Asked: the first four terms.

Concept used: each term = the term before it + d. Why it applies: this is the definition of an AP.

  1. 1

    (a)

    −6-6−6; −6+2.5=−3.5-6 + 2.5 = -3.5−6+2.5=−3.5; −3.5+2.5=−1-3.5 + 2.5 = -1−3.5+2.5=−1; −1+2.5=1.5-1 + 2.5 = 1.5−1+2.5=1.5.

  2. 2

    (b)

    Write 23\dfrac{2}{3}32​ as 46\dfrac{4}{6}64​. Then 46,36,26,16\dfrac{4}{6}, \dfrac{3}{6}, \dfrac{2}{6}, \dfrac{1}{6}64​,63​,62​,61​, which simplify to 23,12,13,16\dfrac{2}{3}, \dfrac{1}{2}, \dfrac{1}{3}, \dfrac{1}{6}32​,21​,31​,61​.

  3. 3

    (c)

    Find d: d=a2−a1=4−9=−5d = a_2 - a_1 = 4 - 9 = -5d=a2​−a1​=4−9=−5.

Worked example 4

Finding x from three consecutive terms

Question. (a) For what value of x are 2x+12x + 12x+1, 3x−23x - 23x−2 and 2x+92x + 92x+9 three consecutive terms of an AP? Write the three terms. (b) Find the values of x for which x2x^2x2, 4x4x4x and 151515 are three consecutive terms of an AP, and write the terms each time.

Given: three consecutive terms in terms of x. Asked: x and the terms.

Common mistakes!

  • d=a1−a2d = a_1 - a_2d=a1​−a2​ (e.g. d=5d = 5d=5 for 12,7,212, 7, 212,7,2)

    d is what you add to move forward.

    d=a2−a1=7−12=−5d = a_2 - a_1 = 7 - 12 = -5d=a2​−a1​=7−12=−5.

  • Calling a list an AP after one difference

    The pattern can break later (4,7,10,144, 7, 10, 144,7,10,14).

    Check every difference you are given.

  • "5,5,5,…5, 5, 5, \ldots5,5,5,… is not an AP — nothing is added"

    Adding 0 is allowed.

    A constant list is an AP with d=0d = 0d=0.

  • Using 2b=a+c2b = a + c2b=a+c with the terms in the wrong order

    b must be the middle term of the three.

    Write the three terms in order first.

  • 20−5=15\sqrt{20} - \sqrt{5} = \sqrt{15}20​−5​=15​

    Roots cannot be subtracted under one root sign.

    Simplify: 25−5=52\sqrt{5} - \sqrt{5} = \sqrt{5}25​−5​=5​.

Key points

  • An AP: every term after the first = the term before it + d (the same d each time).
  • d=ak+1−akd = a_{k+1} - a_kd=ak+1​−ak​ — a term minus the term before it; d can be positive, negative or 0.
  • General form: a,a+d,a+2d,…a, a + d, a + 2d, \ldotsa,a+d,a+2d,…; you need both a and d to fix an AP.
  • To test a list, check every difference; simplify fractions, surds and algebra first.
  • a, b, c consecutive in an AP ⇔ 2b=a+c2b = a + c2b=a+c.
