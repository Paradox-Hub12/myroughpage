This section currently holds the Arithmetic Progressions items from the CBSE Mathematics Sample Question Papers 2026-27 and 2025-26 — Mathematics Standard (041) and Mathematics Basic (241) — answered with their official marking schemes (newest first). Past year board questions, and the "Exam focus" analysis, will be added once the papers are sourced.

Both 2026-27 sample papers state that there is no change in the question paper design and assessment pattern for 2026-27, so the 2025-26 items remain good practice. Standard and Basic share the same syllabus, so every student should try all twelve items. In each paper this chapter is part of Unit II, Algebra (20 marks, shared with Polynomials, Pair of Linear Equations in Two Variables and Quadratic Equations). None of the four papers has an alternative question for visually impaired candidates on this chapter.

Each item has two parts:

  • Understand it — the full step-by-step explanation: Given / Asked → Concept used (and why) → steps → Check → answer → Common trap.
  • Write it in the exam — the answer as you should write it, following the official marking scheme, with marks shown. Where the scheme gives only a total for a group of lines, the split shown is inferred and marked so.
