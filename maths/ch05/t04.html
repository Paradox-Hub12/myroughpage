Topic 4 of 5

Sum of the first n terms

About 70 minutes · 3 things to learn
By the end you can…
  • Derive S_n = n/2 [2a + (n − 1)d] and S_n = n/2 (a + l).
  • Find S_n, or find n (including from a quadratic in n, deciding whether one or both roots are valid), a or d from a given sum.
  • Find the sum of the first n natural numbers, of odd numbers and of multiples in a range; find a_n from S_n using a_n = S_n − S_(n−1); find the sum of the last k terms.

The story goes that a teacher once asked a class to add all the whole numbers from 1 to 100. One pupil, the young Carl Friedrich Gauss, is said to have answered in moments: 5050. He did not add faster than everyone else — he added smarter, by pairing the numbers. This topic turns his trick into a formula that adds up any AP.

Gauss's pairing idea

Write the sum forwards, then backwards underneath, and add each column:

S=1+2+3+⋯+100S=100+99+98+⋯+1\begin{aligned} S &= 1 + 2 + 3 + \cdots + 100 \\ S &= 100 + 99 + 98 + \cdots + 1 \end{aligned}SS​=1+2+3+⋯+100=100+99+98+⋯+1​Swipe to see the whole equation →

Every column adds to 101, and there are 100 columns. So 2S=100×1012S = 100 \times 1012S=100×101, which gives S=5050S = 5050S=5050. The same idea works for every AP.

Deriving the formula for SnS_nSn​

Let SnS_nSn​ be the sum of the first n terms of an AP with first term a and common difference d.

Statement Reason
Sn=a+(a+d)+⋯+[a+(n−1)d]S_n = a + (a + d) + \cdots + [a + (n - 1)d]Sn​=a+(a+d)+⋯+[a+(n−1)d] The first n terms written forwards. Call this (1).
Sn=[a+(n−1)d]+[a+(n−2)d]+⋯+aS_n = [a + (n - 1)d] + [a + (n - 2)d] + \cdots + aSn​=[a+(n−1)d]+[a+(n−2)d]+⋯+a The same terms written backwards. Call this (2).
Each column of (1) and (2) adds to 2a+(n−1)d2a + (n - 1)d2a+(n−1)d. The first column is a+[a+(n−1)d]a + [a + (n - 1)d]a+[a+(n−1)d]. Moving one column to the right adds d to the top term and takes d away from the bottom term, so the column total never changes.
2Sn=n[2a+(n−1)d]2S_n = n[2a + (n - 1)d]2Sn​=n[2a+(n−1)d] Adding (1) and (2): there are n columns, each with the same total.
Sn=n2[2a+(n−1)d]S_n = \dfrac{n}{2}[2a + (n - 1)d]Sn​=2n​[2a+(n−1)d] Divide both sides by 2.
Sn=n2(a+l)S_n = \dfrac{n}{2}(a + l)Sn​=2n​(a+l) 2a+(n−1)d=a+[a+(n−1)d]=a+l2a + (n - 1)d = a + [a + (n - 1)d] = a + l2a+(n−1)d=a+[a+(n−1)d]=a+l, where l=anl = a_nl=an​ is the last of the n terms.

Which sum formula?

  • Use Sn=n2(a+l)S_n = \dfrac{n}{2}(a + l)Sn​=2n​(a+l) when you know the last term of the terms being added. Here l must be the nth term — the last of these n terms, not the last term of some longer list.
  • Otherwise use Sn=n2[2a+(n−1)d]S_n = \dfrac{n}{2}[2a + (n - 1)d]Sn​=2n​[2a+(n−1)d].

Two special sums: 1+2+3+⋯+n=n(n+1)21 + 2 + 3 + \cdots + n = \dfrac{n(n + 1)}{2}1+2+3+⋯+n=2n(n+1)​ (here a=1a = 1a=1, l=nl = nl=n), and the first n odd numbers 1+3+5+⋯+(2n−1)=n2(1+2n−1)=n21 + 3 + 5 + \cdots + (2n - 1) = \dfrac{n}{2}(1 + 2n - 1) = n^21+3+5+⋯+(2n−1)=2n​(1+2n−1)=n2.

Finding n from a sum

Putting a known sum into the formula gives a quadratic in n. Solve it (factorise, as in Chapter 4) and test both roots:

  • A negative root, or one that is not a whole number, is rejected: n counts terms.
  • If both roots are positive whole numbers, the sum really is reached twice. This can happen only when the terms change sign (a and d have opposite signs): the terms between the two answers add up to 0. Then both are valid — unless the story rules one out (for example, it would need a negative number of objects in a row).

Quick reminder (Chapter 4). To factorise an2+bn+can^2 + bn + can2+bn+c, find two numbers whose product is a×ca \times ca×c and whose sum is b, and split the middle term. For 2n2+3n−2302n^2 + 3n - 2302n2+3n−230: product −460-460−460, sum 3 → 23 and −20-20−20, so 2n2+23n−20n−230=(2n+23)(n−10)2n^2 + 23n - 20n - 230 = (2n + 23)(n - 10)2n2+23n−20n−230=(2n+23)(n−10).

Going backwards: ana_nan​ from SnS_nSn​

The sum of the first n terms minus the sum of the first n−1n - 1n−1 terms leaves the nth term:

an=Sn−Sn−1(n≥2),a1=S1a_n = S_n - S_{n-1} \quad (n \geq 2), \qquad a_1 = S_1an​=Sn​−Sn−1​(n≥2),a1​=S1​Swipe to see the whole equation →

The sum of the last k terms

The last k of n terms are themselves an AP, from the (n−k+1)(n - k + 1)(n−k+1)th term to the last term l. So their sum is k2(an−k+1+l)\dfrac{k}{2}(a_{n-k+1} + l)2k​(an−k+1​+l). A second route: Sn−Sn−kS_n - S_{n-k}Sn​−Sn−k​.

Common mistakes!

  • Teachers see finding n and choosing the right formula as two of the four commonest reasons for lost marks in this chapter.

  • Finding n

  • Keeping a negative or fractional root ("n=−232n = -\dfrac{23}{2}n=−223​ or 10")

    n counts terms.

    Reject it and say why: "n must be a positive whole number".

  • Throwing away a second positive whole root without a reason

    The sum can be reached twice when the terms change sign.

    Test both: work out SnS_nSn​ for each. Reject only for a stated reason.

  • Forgetting to test the story

    A root can fit the equation but not the situation (a negative number of logs in the top row).

    Find the term at that n and ask "does this make sense?".

  • Dividing only one side of n2(…)=S\dfrac{n}{2}(\ldots) = S2n​(…)=S

    The equation changes.

    Multiply both sides by 2 first, or divide the whole bracket by 2.
