Grouped data — class limits, class size h = upper − lower, class mark xi=lower+upper2x_i = \dfrac{\text{lower} + \text{upper}}{2}xi​=2lower+upper​. A value on a boundary goes into the higher class. Inclusive classes (21 – 30, 31 – 40) become continuous by moving each end half the gap (20.5 – 30.5); the class marks do not change. The grouped mean assumes every value sits at its class mark, so it is an estimate.

Together — mean = fair share (pulled by extremes), median = middle, mode = most common. Empirical relation (approximate): 3 Median=Mode+2 Mean3\,\text{Median} = \text{Mode} + 2\,\text{Mean}3Median=Mode+2Mean. Adding k to every value adds k to all three. Keep fractions exact; round to two decimal places at the end. Not in the syllabus: ogives (cumulative frequency graphs); median and mode with unequal classes.
