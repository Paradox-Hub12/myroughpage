About the question text: each NCERT question is shown in full above its solution, with its textbook location. The book prints most data tables across the page; here every table is turned to run down the page (class in the first column, frequency in the second) so that it fits a phone screen — the numbers are unchanged. The solutions are our own. This chapter has Exercise 13.1 with 9 questions (mean), Exercise 13.2 with 6 questions (mode) and Exercise 13.3 with 7 questions (median), so there are 22 solutions below. Rounding: the working keeps exact fractions; each final answer is given to two decimal places (or exactly, when it ends sooner). Where NCERT's printed answer is cut off rather than rounded, the solution says so.

How every solution is laid out: Given / Asked → Concept used (and why it applies here) → Steps, one per line with the reason, and the table → Check → ✅ Final answer → Common trap.
