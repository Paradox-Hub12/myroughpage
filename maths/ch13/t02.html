Topic 2 of 6

Mean of grouped data: the direct and assumed-mean methods

About 50 minutes · 3 things to learn
By the end you can…
  • Find the mean of grouped data by the direct method, using class marks.
  • Find the mean by the assumed-mean method and explain why any assumed mean gives the same answer.
  • Explain why the mean of grouped data is an estimate that can differ from the exact mean of the raw data.

A school notes how long 40 students spend on homework each evening, in groups: 0 – 20 minutes, 20 – 40 minutes, and so on. You do not know any one student's exact time — only how many students fall in each group. Can you still find the average time? Yes: you make one sensible assumption, and then the Class IX formula works again.

  1. One assumption: each class sits at its class mark

In grouped data we know only how many values lie in each class. So we assume that the values in a class are centred at its class mark (its middle). A class 20 – 40 with frequency 9 is treated as nine values of 30. Then each class mark xix_ixi​ is a value that occurs fif_ifi​ times, exactly as in a Class IX frequency table.

  1. The direct method

xˉ=ΣfixiΣfi\bar{x} = \frac{\Sigma f_i x_i}{\Sigma f_i}xˉ=Σfi​Σfi​xi​​Swipe to see the whole equation →

  1. The grouped mean is an estimate

The assumption "values sit at the class mark" is rarely exactly true. So the mean of grouped data is usually a little different from the mean of the raw data it came from. The raw-data mean is exact; the grouped mean is a good estimate. (Worked example 3 shows both.)

  1. The assumed-mean method: make the numbers smaller

When the class marks are large (₹700, ₹900, ₹1100 …), the products fixif_i x_ifi​xi​ become large too. A short cut:

  1. Choose an assumed mean a — usually a class mark near the middle of the table.
  2. Find the deviation di=xi−ad_i = x_i - adi​=xi​−a of each class mark (negative below a, 0 at a, positive above a).
  3. Find fidif_i d_ifi​di​ and Σfidi\Sigma f_i d_iΣfi​di​.
  4. xˉ=a+ΣfidiΣfi\bar{x} = a + \frac{\Sigma f_i d_i}{\Sigma f_i}xˉ=a+Σfi​Σfi​di​​Swipe to see the whole equation →

Why it works. Taking a away from every value takes a away from their mean. So the mean of the deviations is xˉ−a\bar{x} - axˉ−a, that is, ΣfidiΣfi=xˉ−a\dfrac{\Sigma f_i d_i}{\Sigma f_i} = \bar{x} - aΣfi​Σfi​di​​=xˉ−a. Adding a back gives the formula.

  1. Any assumed mean gives the same answer

Because a is taken away and then added back, the answer does not depend on the choice of a. Choose a class mark near the middle only because the numbers stay small. This also gives you a free check: work the mean again with a different a, and you must get the same answer.

  1. Which method?

  • Small class marks and frequencies → direct method.
  • Large class marks → assumed-mean method (or the step-deviation method of Topic 3).

All the methods give the same mean.

Worked example 1

The direct method

Question. The time 40 students spent on homework one evening is grouped as follows (in minutes): 0 – 20: 4 students; 20 – 40: 9; 40 – 60: 15; 60 – 80: 8; 80 – 100: 4. Find the mean time by the direct method.

Given: five classes of size 20 and their frequencies. Asked: the mean time.

Concept used: direct method, xˉ=ΣfixiΣfi\bar{x} = \dfrac{\Sigma f_i x_i}{\Sigma f_i}xˉ=Σfi​Σfi​xi​​, with the class marks as xix_ixi​. Why it applies: the class marks (10, 30, 50 …) and frequencies are small numbers.

  1. 1

    Class marks: 0+202=10\dfrac{0 + 20}{2} = 1020+20​=10, then 30, 50, 70, 90 (each 20 more than the one before).

  2. 2

    Make the table:

    Time (min) fif_ifi​ xix_ixi​ fixif_i x_ifi​xi​
    0 – 20 4 10 40
    20 – 40 9 30 270
    40 – 60 15 50 750
    60 – 80 8 70 560
    80 – 100 4 90 360
    Total Σfi=40\Sigma f_i = 40Σfi​=40 Σfixi=1980\Sigma f_i x_i = 1980Σfi​xi​=1980
  3. 3

    xˉ=ΣfixiΣfi=198040=49.5\bar{x} = \dfrac{\Sigma f_i x_i}{\Sigma f_i} = \dfrac{1980}{40} = 49.5xˉ=Σfi​Σfi​xi​​=401980​=49.5 minutes.

  4. Check: a second route, the assumed-mean method with a=50a = 50a=50: di=−40,−20,0,20,40d_i = -40, -20, 0, 20, 40di​=−40,−20,0,20,40, so Σfidi=−160−180+0+160+160=−20\Sigma f_i d_i = -160 - 180 + 0 + 160 + 160 = -20Σfi​di​=−160−180+0+160+160=−20 and xˉ=50+−2040=50−0.5=49.5\bar{x} = 50 + \dfrac{-20}{40} = 50 - 0.5 = 49.5xˉ=50+40−20​=50−0.5=49.5 ✔.

  5. Answer The mean homework time is 49.5 minutes.

    Common trap: Using the lower limits (0, 20, 40 …) as xix_ixi​ gives 39.5 minutes — every value is then 10 too small.

Worked example 2

The assumed-mean method

Question. The monthly electricity bills of 50 homes in a colony are: ₹600 – 800: 4 homes; ₹800 – 1000: 8; ₹1000 – 1200: 15; ₹1200 – 1400: 12; ₹1400 – 1600: 7; ₹1600 – 1800: 4. Find the mean bill by the assumed-mean method.

Given: six classes of size ₹200; Σfi=50\Sigma f_i = 50Σfi​=50. Asked: the mean bill.

Concept used: xˉ=a+ΣfidiΣfi\bar{x} = a + \dfrac{\Sigma f_i d_i}{\Sigma f_i}xˉ=a+Σfi​Σfi​di​​ with di=xi−ad_i = x_i - adi​=xi​−a. Why it applies: the class marks (₹700 … ₹1700) are large, so the products fixif_i x_ifi​xi​ would be large.

    Class marks: 700, 900, 1100, 1300, 1500, 1700.

  2. 2

    Choose a=1100a = 1100a=1100 (a class mark near the middle); then di=xi−1100d_i = x_i - 1100di​=xi​−1100.

    Bill (₹) fif_ifi​ xix_ixi​ di=xi−1100d_i = x_i - 1100di​=xi​−1100 fidif_i d_ifi​di​
    600 – 800 4 700 −400 −1600
    800 – 1000 8 900 −200 −1600
    1000 – 1200 15 1100 0 0
    1200 – 1400 12 1300 200 2400
    1400 – 1600 7 1500 400 2800
    1600 – 1800 4 1700 600 2400
    Total Σfi=50\Sigma f_i = 50Σfi​=50 Σfidi=4400\Sigma f_i d_i = 4400Σfi​di​=4400
  3. 3

    xˉ=a+ΣfidiΣfi=1100+440050=1100+88=1188\bar{x} = a + \dfrac{\Sigma f_i d_i}{\Sigma f_i} = 1100 + \dfrac{4400}{50} = 1100 + 88 = 1188xˉ=a+Σfi​Σfi​di​​=1100+504400​=1100+88=1188

  4. Check: another assumed mean must give the same answer. With a=1300a = 1300a=1300: di=−600,−400,−200,0,200,400d_i = -600, -400, -200, 0, 200, 400di​=−600,−400,−200,0,200,400; Σfidi=−2400−3200−3000+0+1400+1600=−5600\Sigma f_i d_i = -2400 - 3200 - 3000 + 0 + 1400 + 1600 = -5600Σfi​di​=−2400−3200−3000+0+1400+1600=−5600; xˉ=1300+−560050=1300−112=1188\bar{x} = 1300 + \dfrac{-5600}{50} = 1300 - 112 = 1188xˉ=1300+50−5600​=1300−112=1188 ✔.

Worked example 3

The exact mean and the grouped mean

Question. In Topic 1, Worked example 4, twenty students scored 12, 25, 31, 18, 40, 27, 33, 20, 45, 30, 22, 38, 29, 35, 10, 41, 26, 30, 17, 36, and these marks were grouped as 10 – 20: 4; 20 – 30: 6; 30 – 40: 7; 40 – 50: 3. (a) Find the exact mean from the list. (b) Find the mean from the grouped table. (c) Why are they different?

Given: the raw marks and the grouped table. Asked: both means and the reason they differ.

Concept used: mean = sum ÷ number (raw data); direct method (grouped data). Why it applies: the same 20 marks are given in both forms.

  1. 1

    (a) Sum of the 20 marks =565= 565=565; exact mean =56520=28.25= \dfrac{565}{20} = 28.25=20565​=28.25.

  2. 2

    (b) Grouped table:

    Marks fif_ifi​ xix_ixi​ fixif_i x_ifi​xi​
    10 – 20 4 15 60
    20 – 30 6 25 150
    30 – 40 7 35 245
    40 – 50 3 45 135
    Total Σfi=20\Sigma f_i = 20Σfi​=20 Σfixi=590\Sigma f_i x_i = 590Σfi​xi​=590
  3. 3

    Grouped mean =59020=29.5= \dfrac{590}{20} = 29.5=20590​=29.5.

  4. 4

    (c) The grouped method treats the four marks 10, 12, 17, 18 as four 15s, the six marks in 20 – 30 as six 25s, and so on. Here the actual marks add to 565, but the class marks add to 590, so the grouped mean comes out higher.

  5. Check: add the marks class by class: 10 – 20: 12+18+10+17=5712 + 18 + 10 + 17 = 5712+18+10+17=57; 20 – 30: 25+27+20+22+29+26=14925 + 27 + 20 + 22 + 29 + 26 = 14925+27+20+22+29+26=149; 30 – 40: 31+33+30+38+35+30+36=23331 + 33 + 30 + 38 + 35 + 30 + 36 = 23331+33+30+38+35+30+36=233; 40 – 50: 40+45+41=12640 + 45 + 41 = 12640+45+41=126; and 57+149+233+126=56557 + 149 + 233 + 126 = 56557+149+233+126=565 ✔.

  6. Answer (a) 28.25 (b) 29.5 (c) The grouped mean assumes every mark sits at its class mark; that is only approximately true, so 29.5 is an estimate and 28.25 is exact.

    Common trap: Thinking that one of the two answers must be a mistake. Both are right for what they use.

Worked example 4

Inclusive classes

Question. The marks of 40 students are grouped as 11 – 20: 6 students; 21 – 30: 10; 31 – 40: 16; 41 – 50: 8. Find the mean mark.

Given: inclusive classes (a gap of 1 between them). Asked: the mean.

Concept used: direct method. Why it applies: the class marks do not change when inclusive classes are made continuous (Topic 1), so the classes can be used as they are for the mean.

  1. 1

    Class marks: 11+202=15.5\dfrac{11 + 20}{2} = 15.5211+20​=15.5, then 25.5, 35.5, 45.5.

    Marks fif_ifi​ xix_ixi​ fixif_i x_ifi​xi​
    11 – 20 6 15.5 93
    21 – 30 10 25.5 255
    31 – 40 16 35.5 568
    41 – 50 8 45.5 364
    Total Σfi=40\Sigma f_i = 40Σfi​=40 Σfixi=1280\Sigma f_i x_i = 1280Σfi​xi​=1280
  2. 2

    xˉ=128040=32\bar{x} = \dfrac{1280}{40} = 32xˉ=401280​=32

  3. Check: assumed mean a=35.5a = 35.5a=35.5: di=−20,−10,0,10d_i = -20, -10, 0, 10di​=−20,−10,0,10; Σfidi=−120−100+0+80=−140\Sigma f_i d_i = -120 - 100 + 0 + 80 = -140Σfi​di​=−120−100+0+80=−140; xˉ=35.5+−14040=35.5−3.5=32\bar{x} = 35.5 + \dfrac{-140}{40} = 35.5 - 3.5 = 32xˉ=35.5+40−140​=35.5−3.5=32 ✔.

    Common trap: Taking the class marks as 15, 25, 35, 45 (the middle of 10 – 20 and so on). That gives 31.5, which is 0.5 too small.

Common mistakes!

  • Teachers say that wrong class marks, dividing by the number of classes and forgetting to add a back are among the most common reasons for lost marks in this topic.

  • Lower or upper limits used as xix_ixi​

    Each class is represented by its middle.

    xi=lower+upper2x_i = \dfrac{\text{lower} + \text{upper}}{2}xi​=2lower+upper​.

  • Σfixi\Sigma f_i x_iΣfi​xi​ divided by the number of classes

    There are Σfi\Sigma f_iΣfi​ observations, not 5 or 6.

    Divide by Σfi\Sigma f_iΣfi​.

  • Σxi\Sigma x_iΣxi​ used instead of Σfixi\Sigma f_i x_iΣfi​xi​

    Each class mark counts fif_ifi​ times.

    Multiply first: fixif_i x_ifi​xi​, then add.

  • Answer ΣfidiΣfi\dfrac{\Sigma f_i d_i}{\Sigma f_i}Σfi​Σfi​di​​ with a not added back

    That is the mean of the deviations.

    xˉ=a+ΣfidiΣfi\bar{x} = a + \dfrac{\Sigma f_i d_i}{\Sigma f_i}xˉ=a+Σfi​Σfi​di​​.

  • Deviations below a written as positive

    di=xi−ad_i = x_i - adi​=xi​−a is negative when xi<ax_i < axi​<a.

    Write the minus signs; add the negatives and positives separately.

  • Assume the values in each class sit at the class mark xi=lower+upper2x_i = \dfrac{\text{lower} + \text{upper}}{2}xi​=2lower+upper​.
  • Direct method: xˉ=ΣfixiΣfi\bar{x} = \dfrac{\Sigma f_i x_i}{\Sigma f_i}xˉ=Σfi​Σfi​xi​​, from the table Class | fif_ifi​ | xix_ixi​ | fixif_i x_ifi​xi​.
