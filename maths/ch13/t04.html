Topic 4 of 6

Mode of grouped data

About 50 minutes · 3 things to learn
By the end you can…
  • Find the modal class and the mode of grouped data by the formula (equal class sizes, one modal class), including inclusive classes.
  • Interpret the mode and compare it with the mean.
  • Find a missing frequency when the mode is given.

A ration shop wants to know the most common waiting time, so that it can plan its counters. The mean waiting time does not answer that — a few very long waits pull the mean up. What the shop wants is the mode. In grouped data you cannot see the most common single value, but you can see the busiest class — and a formula tells you where inside that class the mode lies.

  1. The modal class

In ungrouped data the mode is the value with the largest frequency. In grouped data we can only see which class has the largest frequency. That class is the modal class, and the mode is a value inside it.

  • Look at the frequencies — not the class marks, not the cumulative frequencies.
  • The syllabus asks only for data with one modal class. If two classes share the largest frequency (the data are bimodal), the formula below cannot be used, and such data are not asked.

  1. The formula

Mode=l+(f1−f02f1−f0−f2)×h\text{Mode} = l + \left(\frac{f_1 - f_0}{2f_1 - f_0 - f_2}\right) \times hMode=l+(2f1​−f0​−f2​f1​−f0​​)×hSwipe to see the whole equation →
Letter Meaning
l lower limit of the modal class
h class size (all classes must be the same size)
f1f_1f1​ frequency of the modal class
f0f_0f0​ frequency of the class before the modal class
f2f_2f2​ frequency of the class after the modal class

Write these five values in a list before you use the formula — that list usually earns a mark of its own.

  1. What the formula says

The mode starts at l and moves a fraction of the way across the class. The fraction is f1−f0(f1−f0)+(f1−f2)\dfrac{f_1 - f_0}{(f_1 - f_0) + (f_1 - f_2)}(f1​−f0​)+(f1​−f2​)f1​−f0​​ — note that 2f1−f0−f2=(f1−f0)+(f1−f2)2f_1 - f_0 - f_2 = (f_1 - f_0) + (f_1 - f_2)2f1​−f0​−f2​=(f1​−f0​)+(f1​−f2​). So the class of size h is split in the ratio (f1−f0):(f1−f2)(f_1 - f_0) : (f_1 - f_2)(f1​−f0​):(f1​−f2​):

  • If the class after is bigger than the class before (f2>f0f_2 > f_0f2​>f0​), the mode lies in the upper half of the modal class.
  • If the class before is bigger (f0>f2f_0 > f_2f0​>f2​), the mode lies in the lower half.
  • If they are equal, the mode is the class mark.

The mode leans towards the bigger neighbour. This gives a quick check on every answer.

  1. Inclusive classes

For classes such as 10 – 19, 20 – 29, first make them continuous (9.5 – 19.5, 19.5 – 29.5 …). Then l is the continuous lower limit (19.5, not 20) and h is the continuous size (10, not 9).

  1. Mode and mean answer different questions

The mode is the most common value; the mean is the fair share. If a few values are very large, the mean is pulled up but the mode is not. NCERT's example: the mode tells you the marks that most students got; the mean tells you the average marks.

Worked example 1

The mode by the formula

Worked example 2

Mode and mean compared

Question. In Topic 2, Worked example 2, the monthly electricity bills of 50 homes were ₹600 – 800: 4; ₹800 – 1000: 8; ₹1000 – 1200: 15; ₹1200 – 1400: 12; ₹1400 – 1600: 7; ₹1600 – 1800: 4, and the mean bill was ₹1188. Find the modal bill and compare it with the mean.

Given: the table and the mean ₹1188. Asked: the mode and what the two values say.

Concept used: the mode formula; the mode is the most common value, the mean the fair share. Why it applies: the classes are equal, with one modal class.

  1. 1

    Largest frequency 15 → modal class ₹1000 – 1200.

  2. 2

    l=1000l = 1000l=1000, h=200h = 200h=200, f1=15f_1 = 15f1​=15, f0=8f_0 = 8f0​=8, f2=12f_2 = 12f2​=12.

  3. 3

    Mode=1000+(15−830−8−12)×200=1000+710×200=1000+140=1140\text{Mode} = 1000 + \left(\dfrac{15 - 8}{30 - 8 - 12}\right) \times 200 = 1000 + \dfrac{7}{10} \times 200 = 1000 + 140 = 1140Mode=1000+(30−8−1215−8​)×200=1000+107​×200=1000+140=1140

  4. 4

    Compare: the most common bill is about ₹1140, while the average bill is ₹1188. The mean is higher because the homes with large bills (₹1400 and above: 11 homes) pull it up; the mode depends only on the busiest classes.

  5. Check: f2=12>f0=8f_2 = 12 > f_0 = 8f2​=12>f0​=8, so the mode is above the class mark 1100 ✔; the split 140:60=7:3140 : 60 = 7 : 3140:60=7:3 matches (15−8):(15−12)(15 - 8) : (15 - 12)(15−8):(15−12) ✔.

  6. Answer Modal bill ≈ ₹1140; mean bill ₹1188. Most homes pay about ₹1140, but on average a home pays ₹1188.

    Common trap: Saying "the mode is ₹1000 – 1200". That is the modal class; the mode is one value, ₹1140.

Worked example 3

Inclusive classes

Question. The ages of 70 visitors to a science museum on one morning were: 10 – 19 years: 9; 20 – 29: 16; 30 – 39: 23; 40 – 49: 14; 50 – 59: 8. Find the modal age.

Given: inclusive classes (gap 1). Asked: the mode.

Concept used: mode formula with the continuous class limits. Why it applies: l and h must come from touching classes.

    Half the gap is 0.5, so the continuous classes are 9.5 – 19.5, 19.5 – 29.5, 29.5 – 39.5, 39.5 – 49.5, 49.5 – 59.5.

  5. Check: f0=16>f2=14f_0 = 16 > f_2 = 14f0​=16>f2​=14, so the mode is in the lower half of 29.5 – 39.5, below the class mark 34.5 ✔; the split 4.375:5.625=7:94.375 : 5.625 = 7 : 94.375:5.625=7:9 matches (23−16):(23−14)(23 - 16) : (23 - 14)(23−16):(23−14) ✔.

A missing frequency from the mode
