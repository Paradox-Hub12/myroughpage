Question: The median of a set of 9 distinct observation is 20.5. If each of the observations of a set is increased by 2,then the median of a new set

The median becomes 20.5+2=22.520.5 + 2 = 22.520.5+2=22.5.
The values went up, not down.
Adding 2 does not double anything.
Every value, including the middle one, has changed.

Given: 9 distinct observations, median 20.5; each increased by 2. Asked: the new median.

Concept used: adding the same number to every observation keeps their order, so the middle value moves by that number (Topic 6). Why it applies: the median is the 5th value in order.

  1. 1

    The 5th value in order was 20.5; after adding 2 to every value, the order is the same and the 5th value is 22.5.

    Reasoning for each option:

    • (A) ✔ The median becomes 20.5+2=22.520.5 + 2 = 22.520.5+2=22.5.
    • (B) ✘ The values went up, not down.
    • (C) ✘ Adding 2 does not double anything.
    • (D) ✘ Every value, including the middle one, has changed.

  2. Check: a small example: 1, 2, 3 (median 2) → 3, 4, 5 (median 4 = 2 + 2) ✔.

    Common trap: Thinking the median "stays in the same place" — the position stays the same, the value does not.
Each observation increases by 2, the order is unchanged, so the median becomes 20.5 + 2 = 22.5. Answer: (A) median is increased by 2
